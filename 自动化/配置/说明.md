# 自动化工具

通过 Trae IDE + Selenium + Chrome 实现小说章节自动发布。

## 目录结构

```
自动化/
├── 发布器/
│   └── 发布器.py          # 番茄小说自动发布主脚本
├── 配置/
│   ├── 发布配置.yaml       # 平台凭证、发布策略等
│   ├── 需求.txt            # Python 依赖
│   └── 说明.md             # 本文件
└── 日志/
    ├── 已发布章节.txt       # 已发布记录（用于增量发布）
    └── 发布日志_*.log       # 每次运行的详细日志
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r 自动化/配置/需求.txt
```

### 2. 配置凭证

编辑 `自动化/配置/发布配置.yaml`：

```yaml
凭证:
  手机号: "15871764862"

作品:
  书名: "万古神龙：我的血脉全靠吞"
```

### 3. 运行发布

```bash
# 增量发布（只发布未发布过的章节）
python 自动化/发布器/发布器.py

# 预览模式（不实际发布，仅列出待发布章节）
python 自动化/发布器/发布器.py --dry-run

# 发布指定章节
python 自动化/发布器/发布器.py --chapter 1

# 批量发布
python 自动化/发布器/发布器.py --start 1 --end 10
```

## 工作流程

```
执行/章节/第001章·觉醒.md  ──┐
执行/章节/第002章·噬脉诀.md  ──┤
执行/章节/第003章·第一次吞噬.md──┤
                                ├──→ 发布器.py ──→ Chrome ──→ 番茄小说
自动化/配置/发布配置.yaml ──────┘                     作家后台
自动化/日志/已发布章节.txt  ───────────────────────── 防止重复发布
```

## 安全提醒

- `发布配置.yaml` 包含手机号等敏感信息，**不要提交到 Git**
- 建议将 `自动化/配置/发布配置.yaml` 加入 `.gitignore`
- 首次使用建议先 `--dry-run` 预览
