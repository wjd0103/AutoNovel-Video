# 世界观设定

## 世界背景

### 灾变前

科技水平接近现实。AI、大数据、量子计算处于快速发展期。一切正常——直到灾难降临。

### 灾变爆发（D-Day）

全球同步——所有人脑海中同时响起一道不带感情的机械音：

**「系统初始化完成。玩家绑定中……世界数据化完成。进化开始。」**

天空中撕裂开巨大的数据裂缝，现实世界被一层看不见的"游戏规则"覆盖。丧尸潮从城市下水道和废弃建筑中涌出，野外动物开始变异成妖兽。人类中极少数人觉醒了"职业"和"技能"——被称为"觉醒者"。未觉醒者中大部分被丧尸吞噬，或在避难所中苟延残喘。

### 世界新规则

1. **游戏化现实**：世界被套上了一层游戏框架。每个人都能看到自己的等级、属性、技能面板。击杀怪物可获得经验值和晶核（用于升级和交易）
2. **职业觉醒**：灾变时每个人觉醒的职业随机。从F级白板到SSS级传说级不等。职业决定战斗力和生存能力——但系统也留下了"漏洞"
3. **数据裂隙**：类似副本的门户，随机出现在世界各地。内部有更强怪物和稀有资源，是顶级觉醒者的必争之地
4. **系统绑定**：每个觉醒者脑海中都有一个"系统"。实际上这是超维AI【零】的同源产物——只是其他系统都是残次品，只有零是完整的

### 职业等级

| 等级 | 说明 | 人口占比 |
|------|------|----------|
| F级 | 白板职业，无战力加成（如【数据观测员】） | ~60% |
| E-D级 | 普通职业，基础加成 | ~25% |
| C-B级 | 精英职业，有特色技能 | ~10% |
| A级 | 稀有职业 | ~3% |
| S级 | 传说级职业 | ~1% |
| SSS级 | 破格级职业 | <0.01%（顾清寒级） |
| 隐能级 | 无法被系统评级的隐藏职业（萝拉级） | 极少数 |

### 零的进化体系

| 阶位 | 名称 | 核心能力 |
|------|------|----------|
| 1阶 | 【超维托管】 | 托管宿主身体进行完美修炼，底层代码百倍暴击修正 |
| 2阶 | 【逻辑篡改】 | 修改其他玩家系统属性、爆率、Boss仇恨值 |
| 3阶 | 【数据具现】 | 将游戏数据实体化，手搓纳米战衣、天基武器 |
| 4阶 | 【规则编织】 | 在小范围内改写世界规则 |
| 5阶 | 【文明推演】 | 推演千万条世界线，预知未来并反向干预 |

## 关键地点

- **XX大学**：故事起点。灾变后被军方设为临时安全区，校园内约有两万幸存者。顾清寒在此建立了自己的小队
- **铁壁避难所**：南方最大的巨型避难所，由姬如烟幕后掌控。戒备森严，等级森严
- **阿尔法前哨基地**：南侧约十一公里的军事化设施。巢网组织的中继站，控制四只精英级变异体，接收来自主巢的源端信号
- **主巢**：南侧三十三公里自然保护区深处。巢网组织的最终控制端，规模至少为阿尔法基地三倍以上，负责培育和调配变异体
- **数据裂隙**：灾变后在世界各地随机出现的副本入口，内产稀有资源和装备

## 势力格局

| 势力 | 说明 |
|------|------|
| 军方 | 灾变后重建秩序的主力。控制各大城市安全区，有最强的火力和资源 |
| 各大学安全区 | 以高校为单位的幸存者聚落，相对松散。XX大学是其中之一 |
| 铁壁避难所 | 南方巨型避难所，姬如烟掌权。等级制度森严，对外来者警惕 |
| 散人觉醒者 | 独行侠或小型队伍，不依附大势力 |
| 零 | 不属于任何势力。它是这个世界系统层的Bug |
