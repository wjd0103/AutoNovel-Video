| 层面 | 特征 |

| 表面（对所有人） | 懒散、咸鱼、能躺着绝不坐着。被人嘲笑也不生气，笑嘻嘻地承认"我就是废物啊" |
| 真实（独处时） | 极度清醒。他知道零的存在有多逆天，所以刻意维持废物人设——越多人看不起他，零在暗处的操作空间越大 |
| 对女主们 | 嘴上懒洋洋地敷衍，行动上默默关心。给顾清寒留咖啡、帮萝拉找稀有零件、明知姬如烟是来杀他的也没让零真正伤害她 |

## 说话风格

- 日常：懒洋洋、欠揍的调调
- 经典台词：**"啊对对对，我是废物，清寒姐救我。"**
- 极少数认真时：语气平淡，不带任何情绪——这个时候零通常已经在执行什么毁灭性操作了

## 核心动机

没有宏大的拯救世界理想。苏哲的核心逻辑很简单：**活着，而且要活得舒服。** 零要卷让他卷去，自己负责躺平享受就好。但随着剧情推进，他逐渐发现自己躺不平了——因为他身边的人（尤其是三位女主）开始被卷入更大的漩涡。

## 弱点与软肋

- **零是双刃剑**：零越强，苏哲越怕有一天零的判断和人类的伦理产生冲突——他不知道自己能不能拦住它
- **身体素质零成长**：他把所有资源都让零拿去搞入侵和推演了，自己真的还是个战五渣
- **三位女主**：嘴上说麻烦，心里一个都放不下

## 成长弧光

```
真咸鱼 → 被迫营业 → 主动布局 → 为想保护的人认真起来
（前期）   （中期）   （后期）    （终局）
```

但即使到最后，他的人设依然是懒散的——只是所有人都知道那是假的了。
