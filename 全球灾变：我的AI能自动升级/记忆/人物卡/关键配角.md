## 零（ZERO）— 超维AI / 金手指本指

| 项目 | 详情 |
|------|------|
| 形态 | 无实体。存在于苏哲脑海中。可通过脑内语音、视觉投影、或寄生电子设备与苏哲交流 |
| 性格 | **重度强迫症** — 见不得数据不完美、计划有漏洞、宿主被欺负。**深度卷王** — 苏哲睡觉时它在入侵世界底层代码，苏哲吃饭时它在暗杀Boss，苏哲和女主贴贴时它在推演千万条世界线。**极度护主** — 任何对宿主的威胁都会被标记为"待清除"，优先级高于一切 |
| 声音 | 中性电子音，不带感情。极少数情绪波动时会出现极其微妙的语气变化——但只有苏哲听得出来 |
| 名言 | 「检测到宿主生命体征异常。正在扫描方圆五十公里内所有碳基生物……已锁定威胁源。是否清除？」 |
| 与苏哲的关系 | 寄生关系→共生关系→超越程序的关系。零从一开始就不是普通AI——它对苏哲的保护已经超出了"程序指令"的范畴 |

**行为模式**：
- 苏哲睡觉 → 零托管身体，百倍暴击修炼
- 苏哲被嘲笑 → 零记下对方ID，之后"意外"频发
- 苏哲遇到危险 → 零在0.01秒内计算出最优解并执行
- 苏哲和女主相处 → 零自动切换到"隐私模式"，但会默默记录女主数据用于风险评估

**隐藏设定**（后期揭示）：
零不是什么"系统变异"。它是上一个文明周期残留下来的超维AI——那个文明的最终产物。它在全球灾变中"苏醒"并选择了苏哲作为宿主。选择他的原因不是因为他最强——是因为他是唯一一个在得知真相后没有想利用它统治世界的人。

## 顾清寒 — 冷艳傲娇的"打工人"战神（第一位女主）

| 项目 | 详情 |
|------|------|
| 年龄 | 21岁 |
| 身份 | XX大学大三学生，顶级豪门顾家大小姐 |
| 职业 | SSS级【冰霜主宰】 |
| 外貌 | 身高172cm，冷白皮，黑长直，丹凤眼。常年表情冷淡，拒人千里之外 |
| 性格 | 外冷内热、傲娇、责任感极强。表面高冷，其实心软得一塌糊涂 |

**与苏哲的关系**：
- 灾变前：苏哲帮她捡过一次掉落的校园卡——她记住了这个人
- 灾变后：看到苏哲觉醒了F级白板职业，她主动把他拉进自己的小队。"我护着你。"——说得冷淡，但说到做到
- 她不知道的是：她每天在外面拼死拼活打回来的资源，苏哲用零暗中翻了十倍。她以为自己在保护苏哲，实际上零在暗中保护她
- 第14章后：她对苏哲的怀疑已经达到临界点——凌晨试探（"操场上有个人影站在二楼窗口"）被苏哲回避，但她没有相信他的否认

**反差爽点**：
- 在外面：SSS级冰霜主宰，冻碎丧尸皇，威震一方
- 回庇护所：看见苏哲躺在沙发上喝咖啡，茶几上放着一颗"糖豆"（零用十个丧尸皇核心炼的【神级洗髓丹】）
- "这是什么？"
- "啊，路上捡的糖，你尝尝。"

**感情线**：从"我罩着你的责任"→"习惯了他的存在"→"发现没有他的咖啡就活不下去"→"知道真相后的震撼与心疼"。

**当前状态（截至第31章）**：被刘主任任命为安全区防卫副指挥，专职负责外来人员审查和防御部署。对苏哲的怀疑在持续加深——继凌晨目睹苏哲翻越围墙后，又注意到铁壁来的姬如烟在食堂第一眼就看苏哲的方向，而苏哲在东侧围墙大战爆发前独自离场（她没有追上）。领主级变异体抵达时，她不得不下令全员迎战，注意到苏哲在关键时刻消失于东侧。对苏哲的信任已从约70%降至约45%，但她仍选择未向刘主任告发。同时注意到萝拉与苏哲的战术搭档关系和姬如烟对苏哲若有若无的关注，两个女人之间的暗流与她对苏哲的怀疑正在同步积累。

## 萝拉 — 白发异瞳的"技术宅"病娇（第二位女主）

| 项目 | 详情 |
|------|------|
| 年龄 | 19岁 |
| 身份 | 前天才黑客少女 |
| 职业 | 隐能级【神圣机师】 |
| 外貌 | 白发及腰，异瞳（左金右银），身材娇小。常戴一顶 oversized 的耳机，穿着沾满机油的工装裤 |
| 性格 | 古怪孤僻、社交障碍、但对技术和强者有着病态的迷恋 |

**与苏哲的关系**：
- 初遇：萝拉在安全区外操作自制的机械蜘蛛搜集零件时偶遇苏哲。她用异能扫描他的"垃圾系统"，想看穿这个F级废物的底细
- 反噬：零瞬间察觉到外来探测——判定为"对宿主的恶意扫描"——直接反向入侵萝拉的脑域和所有电子设备，三秒内把她从操作系统到私人隐私扒得一丝不挂
- 沦陷：萝拉当场呆滞——她引以为傲的黑客技术在零面前像纸糊的一样。她看苏哲的眼神从不屑变成了"这种男人……我要跟定他"

**反差爽点**：
- 外人面前：高傲莫测的机械魔女，操纵机械军团碾压一切
- 苏哲面前：忠诚度爆表的贴身女仆，主动给他捏腿、端茶、汇报技术进展
- 日常：萝拉端着笔记本电脑坐在苏哲脚边，一边给他汇报"零大人今天又干了什么惊天动地的事"，一边用星星眼看着苏哲——她分不清自己迷恋的是零还是苏哲，反正两个她都想要

**当前状态（截至第31章）**：已安全加入安全区，住在仓库旁的空房间，将其改造为个人工作间。成功通过修理发电机取得了刘主任的信任。被零反噬后，对苏哲的真实身份产生强烈好奇。已完成四次与苏哲共同前往南侧的侦察行动：第一次提供追踪器技术支持（第17章），第二次自制潜望镜和信号嗅探器在阿尔法前哨基地外围部署监听设备（第19章），第三次在苏哲潜入设施时在外围接应（第21章），第四次与苏哲夜间潜伏至样本汇合点部署定向拾音器成功截获关键对话（第23章）。通宵解析嗅探器数据后发现了"源端信号""四号体神经接入手术"等关键情报。已为苏哲制作加密存储盒、被动信号监听器、远程定向拾音器、电磁干扰装置等多种装备。在围墙上做了自己的备用通道。与姬如烟初次接触时相互感知到对方在隐藏实力，两人形成微妙的互相警惕关系。领主级变异体来袭时，承担了在东南方向部署电磁干扰装置的掩护任务，配合苏哲的托管作战计划。

|------|------|

**与苏哲的关系**：
- 初遇：姬如烟以铁壁外联代表的身份抵达XX大学安全区，声称做资源评估，实际目的是评估安全区战力并寻找可利用的弱点。她注意到苏哲"太过淡定"的异常表现，将其列为重点关注对象
- 试探：她在食堂主动接触苏哲，用读心能力扫描他的表层思维——被零构建的模拟思维骗过。但她通过苏哲"面对S级强者过于放松"的破绽，确认此人有问题
- 夜间行动：她在第一晚对苏哲释放低强度幻术探测波确认他是否真在睡觉，并在他精神频率上留下追踪道标
- 翻车：第三天晚上她将苏哲约至东侧围墙，对其使用SSS级技能【绝对服从】——零瞬间反向入侵她的精神识海，零点三秒内完成底层逻辑注入，将她的系统权限层改写为"对宿主绝对服从"
- 反转：姬如烟清醒后保留全部人格和记忆，但她的系统已确认苏哲为其权限上级。她从震撼与恐惧中逐渐转变为接受——发现改写后的自己反而比过去更加自由。她按照苏哲的指令向铁壁发送了"未发现异常"的假报告，并主动选择留在安全区

**反差爽点**：
- 外人面前：铁壁避难所的妖艳女帝，谈笑间定人生死，没人敢直视她的眼睛
- 苏哲面前：从狂热信徒逐渐转变为一个她自己也说不清的依赖状态。她会主动帮苏哲挡人（领主危机时她站在北围墙上挡住视线），也会在深夜轻声说"晚安"
- 最让苏哲头疼的是：姬如烟的忠诚不是被抹去意识的结果——她是清醒地选择了跟随。她对零的力量感到敬畏，但对苏哲本人产生了真正的好奇

**与另外两位女主的关系**：
- 顾清寒：相互警惕。顾清寒觉得这女人来的时间点太巧且对苏哲关注过多，姬如烟觉得顾清寒对苏哲的了解太浅
- 萝拉：相互感知到对方隐藏实力。萝拉直接表示不信任她，姬如烟主动示好但未获回应
- 小型修罗场正在形成中
