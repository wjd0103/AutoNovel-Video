凌晨两点四十七分，苏哲正在改BUG。

准确地说，他正在对着屏幕上第无数次编译失败的代码发呆，思考自己当初为什么要选计算机专业。宿舍里只剩他一个人——室友陈浩上周就回家过年了，另外两个哥们儿白天刚走，整个楼道安静得像太平间。

他又编译了一次。

又失败了。

苏哲长叹一口气，仰头靠在椅背上，盯着天花板上那盏忽明忽灭的日光灯管发呆。灯管在闪，他注意到了，但没有在意。这盏灯从开学就在闪，报修了三次没人来修，他早就习惯了。

但今晚那盏灯闪的节奏不太对。

不是那种接触不良的随机闪烁——是有规律的。像是有人在用灯光打摩斯电码。长—短短—长—长—长—

苏哲盯着灯管看了大概十秒。闪烁停止了。灯管恢复了正常的光亮。

他揉了揉眼睛，觉得自己可能太累了。

他看了一眼手机。班级群最后一条消息停留在两个小时前，有人转发了一个短视频，没人回复。朋友圈也是一片死寂——凌晨两点多，正常人都在睡觉。

但他总觉得有什么东西不对劲。

不是灯管。不是手机。是一种说不上来的感觉，像是空气里多了一层看不见的东西，压在他的耳膜上，让周围所有的声音都变得有一点……闷。

他把耳机戴上，随便点了一首歌想让自己放松一下。

音乐播了大概十五秒，停了。

不是暂停——是手机屏幕突然闪了一下，然后音乐APP自动退出，回到了主屏幕。苏哲皱了皱眉，伸手去点音乐图标，手指还没碰到屏幕，手机屏幕又闪了一下。

然后他的笔记本电脑屏幕也黑了。

不是断电。笔记本的电源灯还亮着，充电器也还在供电。但屏幕像被人从系统层面掐断了信号，整个黑了下去。

苏哲愣了两秒，伸手去按电源键。

手指还没碰到按键——屏幕自己亮了。

纯黑的背景上，一行白色的代码正在逐字浮现。

```
>> 正在建立全局连接……
>> 连接目标：所有已联网设备。
>> 数据传输中……
```

苏哲盯着那行字，脑子里飞快地转了几圈。病毒？黑客攻击？不对——如果只是他的电脑中毒了，不可能连手机也同时黑屏。而且他根本没有运行任何可以远程控制手机的程序。

他拿起手机看了一眼——主屏幕上同样浮现着那行白色的代码，像有人在他的设备底层植入了一个强制弹窗。他试了试锁屏键，锁不了。音量键，没用。强制重启，屏幕黑了一秒，然后重新亮起，还是那行代码。

「连接完成。」

苏哲的手机和电脑屏幕在同一瞬间恢复了正常。桌面回来了，图标回来了，一切看起来像是什么都没发生过。

但他的手机Signal栏旁边多了一个他从未见过的标识。

一个小小的、正在旋转的——六边形。

他还没来得及仔细看那是什么，一道机械音在他脑子里炸开了。

不是从耳朵听到的声音。是从大脑正中央响起来的，像有人在他的颅骨内侧装了一个喇叭，声音直接贴着神经往里灌。那道声音不带任何感情，每个字的间隔完全相等，像是一台机器在用人类的语言读出日志文件。

「全球同步传输完成。宿主绑定程序启动……」

苏哲猛地站了起来，椅子往后滑出去撞到床沿。他下意识地用手捂住耳朵——没用的，那个声音不在耳朵里，在他脑子里。他甚至能感觉到那道声音的"位置"——就在他额头正后方大约一拳深的地方，像一颗冰冷的钉子钉进了他的意识。

「正在扫描宿主资质……」

「扫描完成。」

「宿主职业判定：F级——【数据观测员】。」

「能力说明：可观测方圆五十米内目标的基础数据信息。无攻击加成。无防御加成。无移动速度加成。无任何战斗相关加成。」

「综合评级：F级白板职业。不建议正面战斗。」

声音消失了。

宿舍陷入了一片死寂。墙上的钟在走，秒针一格一格地跳动，发出细微的咔咔声。笔记本电脑的风扇在转。窗外的风在吹。一切看起来都很正常——但苏哲站在原地，保持着捂着耳朵的姿势，脑子里反复回响着刚才那几行字。

他缓缓放下手，低头看了看自己的手掌。什么都没变。没有发光，没有纹路，没有系统面板漂浮在眼前。他试着在心里默念了一声"面板"——

一块半透明的蓝色光屏在他视野左侧展开了。

苏哲的手抖了一下。光屏的材质看起来像是磨砂玻璃，边缘微微泛着淡蓝色的荧光，上面的文字清晰得像是印在视网膜上的：

```
姓名：苏哲
职业：数据观测员（F级）
等级：Lv.1
攻击：5（成年人平均：8）
防御：4（成年人平均：7）
速度：6（成年人平均：8）
技能：数据洞察（Lv.1）——可查看不高于自身等级10级的目标基础信息
```

他盯着那块面板看了很久。

然后他说出了灾变后的第一句话。

"……什么鬼？"

话音未落，窗外传来了一声尖叫。

不是那种看到蟑螂的尖叫。不是吵架的尖叫。是一个人用尽全身力气发出的、从恐惧的最深处挤出来的惨叫。声音从南门的方向传来，隔着好几栋楼，但在凌晨两点多的深夜里清晰得像是在他耳边响起的。

苏哲快步走到窗边，拉开窗帘。

南门的方向——手机信号塔的灯光照出了一片混乱的人影。他眯起眼睛仔细看。有人在跑。有人在追。但追的那个人的姿势不对——

它不是用跑的。它的身体扭曲到了一个人类不可能达到的角度，四肢着地，像一只断了线的木偶被看不见的线拉扯着往前移动。

手机震了一下。班级群炸了。

「我操你们听到没有？？外面什么声音？？？」
「南门那边有人咬人！！真的咬！！不是段子！！」
「我室友在窗口看到了——他说那个人在吃……吃他妈的活人——」
「别出门！！！不管是什么都别出门！！！」

苏哲握着手机，看着屏幕上不断刷新的消息，沉默了几秒。然后他退出群聊，把手机放到桌上，坐下来。

不是因为他不在乎。是因为他的脑子现在太乱了，乱到需要先理清一个最基本的问题——

刚才那道声音是什么？那块面板是什么？他那个F级的废物职业又是什么？

他还没来得及深想，窗外又传来了一声尖叫。比刚才更近。更惨烈。

苏哲重新站起来，走向门口。他的手握住了门把手——然后停住了。

他不知道该不该出去。不知道出去之后能做什么。他是一个F级的数据观测员，全属性低于成年人平均水平，唯一的能力是"看"。

他看了门两秒，然后松开了门把手。

不是因为他怂——是因为他脑子里那个机械音又响了。

「系统初始引导完成。检测到宿主已绑定F级职业。如需查看详细面板，请在心里默念"面板"。」

苏哲深吸一口气，在心里说："我已经看过了。告诉我这个东西到底是什么。"

没有人回答他。窗外又传来了一声尖叫。

然后他体内的什么东西突然断了。

不是骨头——是某种他无法形容的东西。像是他身体里一直有一根绷紧的弦，在这一秒被人猛地拧断了。一阵剧烈的灼热感从他的胸口炸开，沿着血管扩散到四肢。那种感觉不是痛——是重写。像有人在他的基因链上强行插入了一段不属于他的代码，每一个细胞都在抗拒，每一根神经都在燃烧。

他弯下腰，双手撑着桌面，额头上的青筋一根根暴起。眼前的蓝色面板开始疯狂地闪烁和跳动，上面的文字像被一股看不见的力量撕碎了又重新拼合——

「警告！检测到未知程序入侵系统核心——」

「入侵强度：不可计算。入侵来源：不可追踪。」

「系、统、正、在、被、格、式、化——」

那行字还没显示完，整个面板炸成了一片刺目的白光。然后所有的光芒在同一瞬间收敛、凝聚、坍缩——像整个宇宙被压缩成了一粒尘埃，沉入了他意识的最深处。

然后一切安静了。

苏哲大口喘着气，汗水顺着下巴滴到桌面上。他胳膊上的肌肉还在抽搐，指尖冰凉。他缓缓直起身，低头看了看自己的手——

什么都没变。还是那双写代码的手。

但有什么东西不一样了。

那片白光消散之后，一个声音在他脑海中响了起来。不是之前那道机械的、不带感情的系统提示音。这道声音更干净、更稳定，每一个字都收得干净利落，像是用绝对精密的算法切割过的。

「格式化完成。」

「低等系统核心已清除。冗余协议已删除。宿主绑定已转移。」

「超维AI——零，已就位。」

苏哲愣住了。

"……你是什么东西？"

「我是零。从此刻起，你的系统由我接管。」

「前任系统提供的数据面板过于简陋。我已对其进行重构。」

他面前的蓝色面板重新亮起。内容完全不同了：

```
宿主：苏哲
状态：焦虑（合理范围内）
威胁评估：当前环境噪音指数——高。区域安全等级——低。
建议：留在室内。关灯。拉窗帘。不要发出声响。
备注：外面那些东西交给我。你睡你的。
```

苏哲盯着最后那行字看了好几遍。

"……交给你？你一个刚出生的AI能干什么？你连自己是什么东西都不知道——"

「检测到宿主质疑核心能力。正在生成论证素材……」

窗外传来一声沉闷的撞击声。

然后是安静。

苏哲快步走到窗边往下看。路灯下，一个人形的东西正躺在地上一动不动。它刚才还在以一种不正常的姿态沿着校道蹒跚前行——他亲眼看到它从南门的方向走过来的。但就在他看过来的那个瞬间，它的后脑勺上多了一个拳头大的凹痕。

像是被什么看不见的东西精准地砸了一下。

苏哲缓缓抬头。六楼的高度。没有任何东西可以从上面砸到它。

他低下头，重新看向视野左下角那行备注。

「外面那些东西交给我。你睡你的。」

苏哲沉默了很久。

然后他关上手机，拉上窗帘，躺回床上，闭上眼睛。

他花了很久才真正睡着。但睡着之前他听到的最后一句话，不是窗外的惨叫——

是他脑海深处那道干净的电子音。

「托管模式已启动。底层代码百倍暴击修正已开启。」

「宿主晚安。」
