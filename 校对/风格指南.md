# 校对风格指南 —— 审稿标准（强制）

> 本文档为【校对 Agent】的强制审稿标准，所有章节在发布前必须逐条通过检查。
> 任何一条不通过，即视为此章节不合格，必须打回重写。

---

## 一、字数底线（一票否决）

| 规则 | 标准 | 不通过后果 |
|------|------|-----------|
| WR-01 | 每章正文汉字数 **严格 > 3000 字** | ❌ **打回 Writer 重写**，不允许进入下一环节 |
| WR-02 | 不超过 6000 字（超出可截断拆分） | ⚠️ 建议拆分，但不强制打回 |

检查方式：`len(re.findall(r'[\u4e00-\u9fff]', content))`

**校对报告中必须明确写出：** 当前汉字数、是否达标。

## 二、违禁词清洗（一票否决）

以下高频 AI 降智套话在正文中**严禁出现**。发现一个即视为不合格，打回 Editor 精修。

### 2.1 违禁词列表

| 编号 | 违禁词/短语 | 说明 |
|------|------------|------|
| BW-01 | `不得不说` | 过渡套话，直接删或用更自然的表达 |
| BW-02 | `某种意义上` | 模糊限定词，删掉不影响句意 |
| BW-03 | `他的嘴角微微上扬` | AI 模板化表情描写，改为具体动作 |
| BW-04 | `眼神中闪过一丝复杂` | 伪深度描写，改为具体的心理或行动 |
| BW-05 | `仿佛` / `好似` / `宛如` | 每章最多出现 2 次，超出需删减 |
| BW-06 | `微微` / `轻轻` / `淡淡地` | 滥用程度副词，每章同类词不超过 3 次 |
| BW-07 | `某种` / `某种程度` | 模糊化用词，改为具体指代 |
| BW-08 | `似乎` / `好像` | 不确定语气词，每章不超过 3 次 |
| BW-09 | `就在这时` | 过渡套话，改为具体的时间或场景描述 |
| BW-10 | `忽然` / `突然` | 每章不超过 2 次，超出需替换 |
| BW-11 | `心中一惊` / `心头一凛` | 模板化反应，改为具体身体反应 |
| BW-12 | `深吸一口气` | 每章不超过 1 次 |
| BW-13 | `一股暖流` / `一股寒意涌上心头` | AI 万能句式，必须删改 |
| BW-14 | `空气仿佛凝固了` | 高度模板化，严禁出现 |
| BW-15 | `说不清道不明` | 含 BW-01 变体，严禁出现 |
| BW-16 | `不知为何` | 弱化叙事逻辑，每章不超过 1 次 |

### 2.2 违禁词处理方式

1. **发现违禁词** → 在校对报告中列出具体位置（段落/行号）
2. **明确统计**："违禁词共计 X 处，分布在 X 个段落"
3. **处理标准**：违禁词 >= 3 处 → **不合格，打回 Editor 精修**

## 三、爽点审查（重要但不一票否决）

每章必须完成**至少一个**完整的剧情闭环，给读者提供阅读爽感。

### 3.1 爽点类型清单

| 编号 | 爽点类型 | 示例 |
|------|---------|------|
| SP-01 | **金手指展现** | 主角展示新的血脉能力、吞噬进化、突破境界 |
| SP-02 | **反派被打脸** | 反派轻视主角 → 主角用实力碾压 → 反派震惊 |
| SP-03 | **身份反转** | 隐藏身份揭露 → 周围人态度大转变 |
| SP-04 | **智斗碾压** | 主角用计谋或信息差碾压对手 |
| SP-05 | **宝藏或机缘获取** | 获得新的宝物、功法、传承 |
| SP-06 | **情感共鸣** | 战友或亲友之间的坚守与牺牲 |
| SP-07 | **伏笔回收** | 前文埋设的伏笔在本章得到呼应或揭示 |

### 3.2 爽点审查流程

1. 识别本章试图完成的爽点类型
2. 检查爽点是否形成了完整的 **起→承→转→合** 闭环
3. 如果爽点**未完成**（如：刚展示金手指就被打断、反派未被打脸就结束了该章）：
   - 在校对报告中标注：`[爽点未闭环] 类型：SP-02，问题：xxx`
   - 提出具体修改建议
   - ⚠️ 不强制打回，但必须记录

### 3.3 校对报告爽点摘要格式

```
[爽点检查]
完成闭环：SP-01 金手指展现（主角吞噬三阶妖兽成功突破四阶）
未闭环：SP-02 反派被打脸（冲突刚展开章节就结束）
建议：下一章开头先完成反派被打脸闭环，再接新剧情
```

## 四、硬性质量检查清单

以下检查项必须全部通过。一项不通过则打回。

- [ ] Q01：字数 > 3000 汉字
- [ ] Q02：违禁词数量 < 3 处
- [ ] Q03：无超过 8 行的长段落（手机阅读友好）
- [ ] Q04：少用句号，多用逗号和感叹号、问号
- [ ] Q05：少用破折号进行补充说明
- [ ] Q06：对话独立成段，说话人和对话在同一段
- [ ] Q07：至少包含一个完整的爽点闭环
- [ ] Q08：人物行为符合人物卡设定（主角不降智、反派不弱化）
- [ ] Q09：力量体系无前后矛盾（如：三阶打不过二阶的 bug）
- [ ] Q10：地名或机构名与设定一致
- [ ] Q11：章节结尾有钩子（悬念、转折、预告），引导读者追更
- [ ] Q12：无 `# 第N章` 标题行（以正文直接开头）

## 六、通用写作规则（参考）

以下为通用风格规范，不强制检查，但在精修时尽量遵守。

- 标点：中文全角标点，引号使用 `""`，省略号使用 `……`
- 段落：每段不超过 8 行（硬性 Q03 已覆盖），手机阅读友好
- 句号使用：少用句号，多用逗号和感叹号、问号（硬性 Q04 已覆盖）
- 破折号使用：少用破折号进行补充说明（硬性 Q05 已覆盖）
- 数字：除年份外，尽量使用中文数字（"三人"而非 "3人"）
- 对话：说话人 + 动作 + 对话，避免大段纯对白
- 心理活动：用单引号 `'...'` 包裹
- 人称：全篇统一，不混用 "他/她/它"
