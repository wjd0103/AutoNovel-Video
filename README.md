# 自动化网文生产工具

基于 Trae IDE + DeepSeek V4 Pro 构建的 AI 辅助网文创作流水线。支持多部小说并行创作。

## 项目结构

```
小说模型/                                    # 仓库根目录
├── README.md
│
├── 配置/                                    # 通用配置（跨小说共享）
│   └── AI配置.md                             #   AI 模型配置与 Prompt 模板
│
├── 自动化/                                   # 自动发布工具（跨小说共享）
│   ├── 发布器/发布器.py                       #   番茄小说浏览器自动化发布
│   ├── 配置/
│   │   ├── 发布配置.yaml                     #     平台/作品/发布策略
│   │   ├── 需求.txt                          #     Python 依赖
│   │   └── 说明.md                           #     使用说明
│   └── 日志/                                 #     发布记录与运行日志
│
├── 脚本/                                     # 通用脚本
│   ├── 合并章节.py                           #   章节合并脚本
│   └── 格式化文本.py                          #   文本格式化脚本
│
├── 校对/                                     # 校对规则（跨小说共享）
│   └── 风格指南.md
│
├── 万古神龙：我的血脉全靠吞/                    # 📖 小说项目
│   ├── 项目配置.md                            #   本小说专属配置
│   ├── 记忆/                                  #   AI 长期记忆
│   │   ├── 世界观/                            #     力量体系、地图…
│   │   ├── 人物卡/                            #     主角、配角…
│   │   └── 剧情线/                            #     主线、支线、伏笔…
│   ├── 策划/
│   │   └── 大纲.md                            #   分卷大纲 + 章节细纲
│   ├── 执行/
│   │   └── 章节/                              #   章节正文 (.md)
│   └── 输出/                                  #   合并全文等导出产物
│
└── 你的第二本小说/                             # 📖 第二个小说项目（未来）
    ├── 项目配置.md
    ├── 记忆/
    ├── 策划/
    ├── 执行/
    └── 输出/
```

## 核心设计

| 层级 | 目录 | 说明 |
|------|------|------|
| **通用层** | `配置/` `自动化/` `脚本/` `校对/` | 跨小说共享，工具与规则不绑定任何一部作品 |
| **小说层** | `万古神龙：我的血脉全靠吞/` | 每部小说独立目录，包含专属配置、记忆、章节 |

新增小说只需在根目录下创建同名文件夹，放入 `项目配置.md` 和 `记忆/` 即可。

## 工作流

```
策划 Agent (Planner)
  │ 输入: 小说目录/记忆/ 下的世界观 + 人物卡 + 剧情线
  │ 输出: 小说目录/策划/大纲.md
  ▼
执行 Agent (Writer)
  │ 输入: 小说目录/策划/大纲.md + 小说目录/记忆/ 设定
  │ 输出: 小说目录/执行/章节/*.md
  ▼
校对 Agent (Proofreader)
  │ 输入: 小说目录/执行/章节/*.md
  │ 规则: 校对/风格指南.md
  │ 输出: 校对报告 + 精修章节
  ▼
自动化脚本
  │ 脚本/合并章节.py → 合并全文
  │ 脚本/格式化文本.py → 格式化文本
  ▼
自动发布
  │ 自动化/发布器/发布器.py → Selenium + Chrome → 番茄小说作家后台
  ▼
小说目录/输出/  最终交付产物
```

## 快速开始

### 1. 创建小说项目
在根目录下创建小说文件夹，复制 `项目配置.md` 模板：
```bash
mkdir -p "我的新小说/记忆/世界观"
mkdir -p "我的新小说/记忆/人物卡"
mkdir -p "我的新小说/记忆/剧情线"
mkdir -p "我的新小说/策划"
mkdir -p "我的新小说/执行/章节"
mkdir -p "我的新小说/输出"
```

### 2. 填充 AI 长期记忆
在 `你的小说/记忆/` 下创建设定文件。

### 3. 策划 → 执行 → 校对
使用 Agent 基于记忆生成大纲、逐章写作、精修。

### 4. 发布
```bash
pip install -r 自动化/配置/需求.txt
python 自动化/发布器/发布器.py --dry-run    # 预览
python 自动化/发布器/发布器.py              # 增量发布
```

### 5. 合并与导出
```bash
python 脚本/合并章节.py                     # 自动发现所有小说并合并
python 脚本/合并章节.py "万古神龙：我的血脉全靠吞"  # 指定小说
```
