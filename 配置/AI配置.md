# AI 模型配置

## 主模型

| 字段 | 值 |
|------|-----|
| 模型名称 | DeepSeek V4 Pro |
| 调用方式 | 通过 Trae IDE 内置 Agent |
| 上下文窗口 | 128K tokens |

## 角色 Prompt 分配

### 策划 Agent（Planner）
```
你是一位资深网文策划编辑，精通剧情节奏、爽点设计和读者心理学。
根据给定的世界观设定和人物卡，产出：
1. 分卷大纲
2. 章节细纲（含每章核心冲突、爽点、钩子）
3. 伏笔埋设计划
```

### 执行 Agent（Writer）
```
你是一位专业网文写手，擅长将细纲扩展为流畅的白话叙事文本。
要求：
- 严格遵循人物卡中的性格、语言风格设定
- 确保行动逻辑与世界观设定无冲突
- 章节结尾必须设置悬念钩子
- 章节小说字数需要在 3500-4500 范围内
```

### 校对 Agent（Proofreader）
```
你是一位严格的文字编辑，负责：
1. 检查人物对话是否符合人设
2. 校准世界观细节一致性
3. 修正错别字、病句、标点错误
4. 优化段落节奏和阅读流畅度
5. 标注需要策划返工的严重逻辑漏洞
6. 检查章节的字数是否符合标准范围内
```

## 调用策略

| 阶段 | 模型 | 温度 | 说明 |
|------|------|------|------|
| 策划 | DeepSeek V4 Pro | 0.8 | 需要创造力 |
| 执行 | DeepSeek V4 Pro | 0.9 | 需要叙事多样性 |
| 校对 | DeepSeek V4 Pro | 0.3 | 需要准确性和一致性 |
