## 工作流配置

```
[策划] → [执行] → [校对] → [输出]
  │        │        │
  ▼        ▼        ▼
策划/   执行/章节/  校对/
```

### 策划阶段 (策划/)
- 产出：大纲、细纲、章节摘要
- 依赖：记忆/世界观/ + 记忆/人物卡/ + 记忆/剧情线/

### 执行阶段 (执行/章节/)
- 产出：原始章节正文
- 依赖：策划/ 产出 + 记忆/ 设定

### 校对阶段 (校对/)
- 产出：符合风格指南的精修文本
- 校验项：人设一致性、世界观一致性、错别字、标点规范
